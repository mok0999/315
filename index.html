이 턴의 원본 텍스트를 수정해요. (수정하면 이 턴의 형광펜은 초기화됩니다)

📥 로그 추출하기 (크랙 → 아카이브)

크랙 대화를 한 번에 긁어와서 여기에 보관하는 방법이에요.

① 추출기 북마크 만들기 (최초 1회)

  1. 아래 코드를 복사해요.
  2. 브라우저에 새 북마크를 만들고, 이름은 로그 추출, URL(주소) 칸에 복사한 코드를 붙여넣어 저장해요.
    (PC: 북마크바 우클릭 → 페이지 추가 / 모바일: 아무 북마크나 만든 뒤 편집해서 주소를 교체)

② 로그 추출하기

  1. 크랙에서 원하는 대화방을 열어요.
  2. 방금 만든 로그 추출 북마크를 눌러요.
  3. 몇 턴을 뽑을지 숫자를 입력해요. 전체는 0 또는 비우기.
  4. 뜬 창에서 Ctrl+A → Ctrl+C로 전체 복사해요.

③ 아카이브에 보관하기

  1. 왼쪽 ＋ 새 로그(또는 폴더의 ＋)를 눌러요.
  2. 복사한 내용을 붙여넣고 만들기 → 소설처럼 페이지로 정리돼요.
  3. 이후엔 아래 입력창에 더 붙여넣어 이어가고, 폴더·스티커·이미지 추출도 써보세요.

⚠️ 추출 결과에서 유저/캐릭터가 뒤바뀌어 나오면, 코드 맨 앞 SWAP_ROLES=false를 true로 바꿔서 북마크에 다시 저장하세요.
